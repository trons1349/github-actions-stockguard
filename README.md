
# StockGuard

Práctica de introducción a GitHub Actions con Python y pytest.

## Objetivo

Clasificar el nivel de inventario de un producto según
las unidades disponibles y el stock mínimo requerido.

## Tecnologías

- Python
- pytest
- Git
- GitHub Actions

## Pruebas

Las pruebas verifican los estados AGOTADO, CRITICO,
BAJO, NORMAL y el manejo de valores inválidos.
